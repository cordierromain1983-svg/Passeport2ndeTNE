PUBLICATION AVEC GITHUB PAGES
1. Décompressez ce ZIP sur votre ordinateur.
2. Créez un nouveau dépôt GitHub (par exemple : passeport-2de-classe-2).
3. Téléversez tous les fichiers de ce dossier à la racine du dépôt, notamment index.html.
4. Ouvrez Settings > Pages.
5. Choisissez « Deploy from a branch », puis la branche main et le dossier /(root), et enregistrez.
6. Attendez l'adresse du site GitHub Pages, puis ouvrez-la pour tester le passeport.

IMPORTANT
- Ne remplacez pas le dépôt Netlify de la première classe : cette version est destinée à un nouveau site.
- Les codes sont intégrés au HTML public : ce sont des identifiants, pas des mots de passe secrets.
- Chaque élève commence avec zéro fiche acquise/validée. La progression est calculée sur 22 fiches.
